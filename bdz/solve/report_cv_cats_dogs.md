# Отчет: Классификация кошек и собак (классические методы CV)

## 1. Данные
- Источник: Kaggle Dogs vs Cats (train.zip), исходно ~25k изображений (cat/dog).
- После разборки: cats = 12 500, dogs = 12 500.
- Основной прогон (быстрый прототип): использовано по 1 200 на класс (всего 2 400), разделение 80/20 (train 1 920, test 480), стратификация.
- Дополнительно выполнен полный прогон на всех 25k изображениях: train ≈ 20 000, test ≈ 5 000 (по ~2 500 на класс).

## 2. Предобработка и признаки
- Размер перед признаками: 128×128.
- Канал: RGB и grayscale (для части методов).
- Признаки:
  - HOG: 9 ориентаций, 8×8 пикс/ячейка, 2×2 блока.
  - Цветовые гистограммы: 32 бина на канал (R,G,B).
  - LBP: 24 точки, радиус 3, гистограмма (26 бинов).
  - GLCM: расстояние 1, углы 0/45/90/135°, метрики contrast/dissimilarity/homogeneity/energy/correlation.
  - Итоговый вектор: 8 242 признака.
- Нормализация: StandardScaler по train.

## 3. Модели и метрики

### Быстрый прогон на подсэмпле (2.4k, test = 480)
- SVM (linear): accuracy **0.6687**.
- SVM (RBF): accuracy **0.7208**.
- RandomForest (300 деревьев): accuracy **0.7333**.
- Лучший результат: RandomForest (accuracy 0.7333). По классам: cat — precision 0.71, recall 0.79; dog — precision 0.76, recall 0.68. Матрица ошибок: коты классифицируются лучше, собаки чаще ошибочно идут в класс "cat".

### Полный прогон на всём train (≈25k, test ≈5k)
- SVM (linear): accuracy **0.6786**.
- **SVM (RBF): accuracy 0.7874** — лучший среди протестированных на полном наборе.
- Конфьюжн-матрица (test ≈5k; по 2 500 на класс):
  - cat→cat: 1 979; cat→dog: 521
  - dog→cat: 542; dog→dog: 1 958
- По классам для SVM (RBF): cat — precision≈0.79, recall≈0.79; dog — precision≈0.79, recall≈0.78.

## 4. Выводы
- Комбинация HOG+цвет+LBP+GLCM + RF дала ~73% accuracy.
- SVM с RBF ~72%, линейный SVM ~67%.
- Ограничение: использована малая выборка (2.4k) относительно полного набора (25k); рост качества ожидаем при увеличении данных и тюнинге.

## 5. Что ещё можно сделать?
